F00–F10 — первый полностью работающий срез; F11–F13 — развитие и ограниченный выпуск. Последовательность намеренно консервативная: уменьшает конфликты AI и риск UI без логики. Независимые части можно распараллелить отдельным явным назначением, не переписывая чужую область.

Статусы: NOT_STARTED — не начато; IN_PROGRESS — есть назначенный владелец и работа; BLOCKED — обязательный доступ/решение/тест отсутствует; REVIEW — результат готов для проверки/ревью; DONE — все обязательные проверки реально пройдены и доказаны. Смена BLOCKED→IN_PROGRESS требует устранения причины, не времени ожидания.

Для новой сессии: AGENTS→PROJECT_CONTEXT→ROAD→одна карточка→минимальные предметные файлы→затронутая реализация. Файлы этапа — индекс/приёмка, не обязательный полный read на каждый небольшой edit.

Оценка A из этапа 1: срез 8–12 человеко-месяцев/4–6 календарных месяцев команды 2–3 специалистов; альфа 22–32 человеко-месяца суммарно. Это исходный диапазон с высоким риском; перед началом F00 уточнить по доступной команде/среде, не обещать неделю благодаря несколькимИИ. Дорожная карта не подтверждает этот срок тестами.

Крупные отчёты — evidence/artifacts по [правилам проверки](../docs/testing/acceptance.md). [WORKLOG](WORKLOG.md) хранит только актуальную передачу контекста.
