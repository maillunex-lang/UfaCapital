## Обязательные тесты

docker compose config; TLS/API/admin smoke; external port checks; migration+compatible rollback; Android real network.

Команды из package scripts/runner фиксируются при реализации, когда реально существуют. Не заменять отсутствующий runner успешным echo. Если зависимость не предоставлена — BLOCKED с точной причиной. Документирование теста не равно его исполнению.
