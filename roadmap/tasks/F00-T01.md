## Обязательные тесты

Фактические godot --version, go version, java -version, sdkmanager --list_installed, docker compose config; smoke SDK/template compatibility; parse frontmatter/paths.

Команды из package scripts/runner фиксируются при реализации, когда реально существуют. Не заменять отсутствующий runner успешным echo. Если зависимость не предоставлена — BLOCKED с точной причиной. Документирование теста не равно его исполнению.

## Ошибки и ограничения

Отсутствие Go SDK/Android SDK, случайная latest версия, несовпадающие templates.

## Доказательства и завершение

Обновить эту карточку ссылкой на run/evidence (task, command, version, exit code, assertion, artifact); кратко ROAD/PROJECT_CONTEXT/WORKLOG. DONE только после всех обязательных тестов и фактической приёмки. Перед коммитом проверить diff, роли/секреты и затронутые regressions. После этапа проверить GitHub SHA. Не использовать эту карточку как разрешение следующей задачи вне пользовательского объёма.
