# UfaCapital

Экономическая MMO «UFACAPITAL: Деловая республика» для Android, Godot 4, landscape. Общая экономика Башкортостана, компании/производство/торговля и алгоритмические ИИ-предприниматели. СерверGo/PostgreSQL на собственномUbuntu VPS, отдельная веб-админка.

Заказчик выбрал концепциюA. Этапы подготовки 1–3 завершены. **Игровой код ещё не создавался; программирование ожидает отдельного разрешения.**
