# uc-admin-assets

Оригинальная проектная инструкция. Применять только в рамках разрешённой задачи.

1. Прочитай задачу, матрицу механика→админка и API. Новая настройка получает специализированную форму в той же задаче.
2. Админский login/роль/сессия проверяются сервером. Отдели просмотр, модерацию, настройку и тестовую выдачу. Для браузера CSRF и безопасные cookie; React не заменяет авторизацию.
3. Показывай старое/новое значение, причину, версию и дату применения. Исторические проводки не редактируются. Опасные изменения имеют предпросмотр последствий.
4. Каждый графический элемент имеет stable ID, тип, назначение, происхождение/лицензию, промпт, размеры, хеш и версию. Редактор поддерживает реальную замену, публикацию и откат, а не только просмотр.
5. Файлы проверяй по декодированному формату, размеру и пикселям. Первый runtime allowlist PNG/WebP; не исполняй SVG/HTML/скрипты. Новая версия атомарно меняет manifest, прежняя доступна для отката.
6. Встроенная замена шрифтов/иконок APK маркируется requires_apk; не обещай runtime-замену неподдерживаемого ресурса. Экономические параметры не меняются текстурой.
7. Проверь UI через Playwright: логин, запрет чужой роли, редактирование, конфликт версии, upload, публикация, откат и аудит. Ожидай конкретный locator/state, не networkidle на активном WS.

Выход: рабочая связанная форма, API и проверки. Генерация новых изображений требует разрешённой задачи, сам редактор её не запускает.
