## ENG-003 — идентификаторы каталога и операций

- Тип: обратимое инженерное решение, не смена концепции.
- Решение: стабильные текстовые коды каталога (`ufa`, `grain`, `mill`, `grain_to_flour`). Операционные сущности (компания, предприятие, заявка, контракт, проводка, пользователь) — UUID. Деньги в API и конфиге — десятичные строки, в базе — bigint.
- Последствия: клиент не складывает деньги сам и не шлёт JSON-числа для сумм. Повтор команды с тем же Idempotency-Key возвращает тот же результат внутри нового конверта `data`.
