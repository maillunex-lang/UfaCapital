# Доверие, права и безопасность

## Учётные записи

Срез: login/password без зависимости от внешнего соцпровайдера; Argon2id с параметрами, проверенными по ресурсам сервера, соль на пароль. Не хранить пароль/refresh token в открытом виде. Короткий access token/opaque session и rotate/revoke refresh; Android хранит секрет через проверенный Keystore-механизм, не в обычном project config. Точная библиотека/плагин Keystore проверяется в F02, без импорта неизвестного кода.

Веб-админка отдельная серверная сессия, HttpOnly/Secure/SameSite, CSRF для мутаций, TOTP/второй фактор для admin. Нельзя публично включать default admin/password. Dev fixture не переносится в prod. Rate limits login/register/команд и ограничение payload; секреты и персональные данные исключены из логов.

## Роли

player; admin_read; catalog_editor; economy_admin; moderator; asset_editor; test_operator; superadmin. Каждая операция проверяет роль и объект, UI-кнопка не защита. Смена прав/entitlement аудируется. Игровой тестовый аккаунт требует TEST_ADMIN marker+test_operator+environment feature flag, команды дают деньги/ресурсы только его разрешённой компании, с причиной и проводкой через ledger. В prod по умолчанию выключено; включение публично заметно, компания исключена из рейтингов и рыночные воздействия отражены в отчёте.

VIP — косметический entitlement, server_time expiry, выдача/отзыв в админке. В срезе нет платёжного процессора и фальшивых успешных платежей. Истечение VIP не останавливает производство и не отбирает экономические слоты.

## Риски и проверки

BOLA/IDOR: чужая company/lot/order не читается/не изменяется. Injection: parameterized SQL, escape HTML, CSP; файлы проходят декодирование/allowlist, хранение вне executable path. Нельзя логировать bearer/cookies/пароли. Конкурентные команды проверяют резервы и владение заново в транзакции. Сервер отвергает отрицательные суммы, переполнение и недопустимые enum/state.

Админские операции не редактируют прошлый ledger; компенсация отдельной записью. Редактор коэффициентов имеет version и effective_at, конфликт обновления=409. Публичные цены не раскрывают частные остатки/память агентов. Связанные аккаунты/подозрительные сделки отмечаются для проверки; IP сам по себе не доказывает мультиаккаунт.

Секреты VPS/GitHub/подписи APK — secret store вне Git. CI на fork без prod credentials. Подписанный APK и HTTPS нужны одновременно: подпись приложения не делает ответы клиента достоверными. Справочник [OWASP ASVS](https://github.com/OWASP/ASVS), применимые проверки фиксируются в карточке; полного сертификата соответствия сейчас нет.
