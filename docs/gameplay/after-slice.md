# Расширение A после первого среза

Только после F10 и анализа наблюдений; это последовательность задач, не автоматическое разрешение новых продуктовых решений.

F11: второй город и первые межгородские маршруты с временем/тарифом/ёмкостью; больше агрегированных групп труда и обучение; дополнительные товары/рецепты только при доказанном спросе. Города выбираются из Башкортостана, Уфа остаётся стартом. Добавлять районы данными/связями, без полной замены UI. Рейтинги прибыли/надёжности/новичков, исключение тестовых и фиктивных сделок.

F12: договорные объединения самостоятельных компаний, роли доступа, общий проект/склад и лимиты бюджета с аудитом; инвестиции в производственные активы, исследования/лицензии умеренной глубины A. Акционерная биржа/поглощения не включаются автоматически: требуют отдельной экономики и утверждения масштаба. Достижения косметические, вклад не даёт волшебных бонусов.

F13: alpha→закрытая beta→ограниченный выпуск после security/load/recovery/Android upgrade tests. Реальная оплата VIP — отдельная разрешённая задача с выбором способа распространения/платёжного провайдера; нет донатных ресурсов/ускорений. Для GooglePlay может потребоватьсяAAB и актуальные политики SDK, для прямого распространения — подписанныйAPK и безопасные обновления с сохранением signing identity.

Для каждой новой системы одновременно: доменная модель, API, клиент, управление в админке, аудит, автотесты и документация. Нельзя объявить расширение завершённым только по каталогу новых товаров.
