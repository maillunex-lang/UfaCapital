# Android UI A

Landscape, Godot 4 Control/Container, Compatibility 2D. Базовая композиция 1280×720 как проектный ориентир; пересчёт размеров и dp проверяется на устройстве, не приравнивается автоматически к пикселям. Сенсорная цель≥48dp, safe areas, масштаб текста и локализованные денежные строки.

## Экранные потоки

Вход/регистрация→обзор компании→Уфа→предприятие→рецепт/склад→рынок→подтверждение сделки→серверный результат. Пять основных вкладок: Обзор, Карта, Рынок, Компания, Партнёры. Партнёры в срезе — профили/контракты, без корпораций.

Обзор: свободные/зарезервированные деньги, прибыль, обязательства, карточки исключений. Предприятие: выпуск, входы, персонал, склад, причина простоя, ожидаемый остаток денег. Карта: реальные координатные связи, активна Уфа, ненастроенные города не изображаются рабочими рынками. Рынок: город/товар, цена, доступный объём, доставка, тип участника; перед подтверждением итог с комиссией и стоимостью доставки.

Состояния каждого потока: loading, empty с объяснением, ready, submitting, success с operation_id, rejected с причиной, timeout с проверкой прежнего key, disconnected/reconnect. Не показывать локальную покупку как завершённую до ответа сервера. Старые данные помечаются временем, а не выдаются за текущий рынок.

Карта/город/предприятие используют небольшой каталог оригинальных иконок и иллюстраций. При вводе элемента создаётся asset ID/промпт, лицензия/происхождение, способ замены. Декоративные элементы без логики заменяемы; встроенные splash/launcher/font могут требовать APK и явно отмечаются в админке.

VIP: косметический статус/срок, без скрытых выгод. Профиль ИИ маркирован на рынке и в договоре. Тестовый admin видит отдельный раздел команд с причиной и историей; обычному игроку доступ закрыт сервером.

## Проверка и бюджет

16:9,20:9, планшет; экранная клавиатура, жест back, потеря сети/возврат из фона, крупный текст, русские названия и большие суммы. Цель:30FPS минимум на эталонном среднем смартфоне 4–6GB RAM, UI обычных экранов стремится к 60; память и размерAPK измеряются, исходные бюджеты фиксируются в F02/F10. Ограниченные списки/pagination, ленивые панели, кэш хешированных текстур и отсутствие подгрузки всей истории.

Первые 5 минут: регистрация/аренда/первая партия, следующие 25 — реальная продажа/контракт и объяснение прибыли. Нельзя заменить отсутствие покупателя фиктивной сделкой. Учебное сопровождение бесплатно и не ускоряет экономическое время.
